    Risk-free rate

    3-month US Treasury bill rate (FRED series DTB3), annualized. The backtest uses the rate known at the previous close to compute excess returns and Sharpe ratios.

    How the data is stored

    A nightly GitHub Actions job downloads everything into a SQLite database, runs the quality checks in SQL, and publishes only if they pass. The database itself is rebuilt on every run and not published; the site ships the prices_usd view and the T-bill rate as one CSV, which is what this page and the backtest read.
